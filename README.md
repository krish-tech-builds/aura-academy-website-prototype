# AURA Academy

A fictional multi-activity academy website prototype built with React and Vite.

## About

AURA Academy was created as a sample project to explore modern web development and demonstrate how an academy could present its activities and events through a clean web experience.

## Features

- Navigation
- Hero section
- Activities section
- Upcoming events section
- Component-based React structure
- Modern visual design

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS
